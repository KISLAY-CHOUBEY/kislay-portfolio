# Kislay Choubey — Anime Cinematic 3D Portfolio

Static portfolio (`public/`) with a Tsukuyomi cursor aura. Deploys on Vercel as a
pure static site; Express is local-dev only.

## Local dev (http://localhost:4200)

```powershell
cd dev
npm install
npm start
```

## Deploy (Vercel)

Import this repo, Framework = Other, Output Directory = `public`, build/install empty.
